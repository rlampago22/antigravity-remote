# Contributing to Antigravity Remote

Thank you for your interest in improving Antigravity Remote!

## How to Contribute

1. **Fork the repository** on GitHub.
2. **Clone your fork**:
   ```bash
   git clone https://github.com/<your-username>/antigravity-remote.git
   cd antigravity-remote
   ```
3. **Create a feature branch**:
   ```bash
   git checkout -b feature/amazing-feature
   ```
4. **Make your changes and test locally**.
5. **Commit your changes**:
   ```bash
   git commit -m "Add amazing feature"
   ```
6. **Push to your branch**:
   ```bash
   git push origin feature/amazing-feature
   ```
7. **Open a Pull Request**!

## Guidelines
- Follow PEP 8 guidelines for Python code.
- Ensure sensitive files (`.env`, personal tokens) are never committed.
- Keep commits concise and descriptive.
